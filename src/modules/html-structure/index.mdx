# HTML — Structure

HTML décrit le sens et l’organisation du contenu d’une page. Une structure sémantique rend les documents plus compréhensibles pour les personnes, les navigateurs et les technologies d’assistance.

## Objectifs

- Construire un document HTML valide avec les métadonnées essentielles.
- Choisir des éléments sémantiques adaptés au rôle du contenu.
- Créer des liens, insérer des images accessibles et structurer une liste.
- Concevoir un formulaire simple avec des champs correctement associés à leurs libellés.
- Vérifier la hiérarchie des titres et la validité du document.

## Cours

### Le document et ses métadonnées

`doctype` indique au navigateur d’utiliser le mode standard. L’attribut `lang` aide les outils d’assistance et les moteurs de recherche à interpréter la langue du document. La balise `meta viewport` permet une mise à l’échelle adaptée aux écrans mobiles.

```html
<!doctype html>
<html lang="fr">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Mon portfolio</title>
  </head>
  <body>
    <h1>Yunus — Développement web</h1>
  </body>
</html>
```

### Organiser le contenu avec le HTML sémantique

Les éléments `header`, `nav`, `main`, `section` et `footer` décrivent les grandes régions d’une page. Un titre doit annoncer le contenu qui suit. On choisit un élément selon son sens, et non selon son apparence, qui sera définie en CSS.

```html
<main>
  <section aria-labelledby="experience">
    <h2 id="experience">Expérience</h2>
    <article>
      <h3>Développeur web</h3>
      <p>Création de pages accessibles et adaptatives.</p>
    </article>
  </section>
</main>
```

### Liens, images et formulaires

Un lien doit annoncer sa destination. Le texte alternatif d’une image informative décrit son contenu utile ; une image purement décorative reçoit un attribut `alt` vide. Chaque champ de formulaire doit être associé à un `label`.

```html
<a href="https://example.org">Consulter le portfolio</a>
<img src="portrait.jpg" alt="Portrait de Yunus">

<label for="email">Adresse e-mail</label>
<input id="email" name="email" type="email" autocomplete="email" required>
```

## Exercices

<Exercise n="1.1" title="Créer le squelette d’une page">
Créez `index.html` pour un portfolio. Ajoutez la langue, l’encodage, l’affichage mobile, un titre de page et un titre principal.

<Solution>

```html
<!doctype html>
<html lang="fr">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Portfolio de Yunus</title>
  </head>
  <body>
    <h1>Portfolio de Yunus</h1>
  </body>
</html>
```

</Solution>
</Exercise>

<Exercise n="1.2" title="Structurer une expérience professionnelle">
Ajoutez une région principale contenant une section « Expérience » et deux postes. Chaque poste comprend un intitulé et une description.

<Solution>

```html
<main>
  <section aria-labelledby="experience">
    <h2 id="experience">Expérience</h2>
    <article>
      <h3>Développeur web</h3>
      <p>Conception et intégration de sites web.</p>
    </article>
    <article>
      <h3>Assistant de projet</h3>
      <p>Coordination de travaux en équipe.</p>
    </article>
  </section>
</main>
```

</Solution>
</Exercise>

<Exercise n="1.3" title="Ajouter une prise de contact">
Créez un formulaire avec un champ de nom, un champ d’adresse e-mail obligatoire et un bouton d’envoi. Associez explicitement les libellés aux champs.
</Exercise>

## Livrable

Réalisez un CV HTML d’une page avec une présentation, une formation, une expérience, une liste de compétences et un moyen de contact. Utilisez des régions sémantiques et vérifiez que tous les éléments restent compréhensibles sans mise en forme CSS.

<Callout type="tip">
Ouvrez la page dans le navigateur et utilisez le panneau d’accessibilité des outils de développement pour vérifier que les régions et les titres racontent bien la structure du document.
</Callout>

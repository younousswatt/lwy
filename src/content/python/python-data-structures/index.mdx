# Structures de données

Ce module explore les structures de données fondamentales en Python : listes, tuples, dictionnaires, et sets. Ces structures permettent de stocker et manipuler des collections de données de manière efficace. Il explique les opérations courantes sur ces structures, les algorithmes de base (recherche, tri), et les bonnes pratiques pour choisir la structure appropriée selon le cas d'usage. À l'issue de ce module, vous serez capable de manipuler efficacement les structures de données Python et de créer un gestionnaire de contacts fonctionnel.

## Objectifs

- Comprendre les listes et leurs opérations (ajout, suppression, tri)
- Comprendre les tuples et leur immutabilité
- Comprendre les dictionnaires et leurs opérations (accès, modification)
- Comprendre les sets et leurs opérations (union, intersection)
- Choisir la structure de données appropriée
- Comprendre les algorithmes de base (recherche, tri)
- Manipuler des données complexes avec ces structures

## Prérequis

- Introduction à Python (scripts, REPL)
- Variables et types (types primitifs)
- Structures de contrôle (conditions, boucles)
- Fonctions (définition, paramètres)

## Cours

### Listes

Les listes sont des collections ordonnées et modifiables d'éléments.

**Création de listes** :

```python
fruits = ["pomme", "banane", "orange"]
nombres = [1, 2, 3, 4, 5]
mixte = [1, "texte", 3.14, True]
vide = []
```

**Accès aux éléments** :

```python
fruits = ["pomme", "banane", "orange"]
premier = fruits[0]    # "pomme"
dernier = fruits[-1]   # "orange"
sous_liste = fruits[0:2]  # ["pomme", "banane"]
```

**Modification d'éléments** :

```python
fruits = ["pomme", "banane", "orange"]
fruits[0] = "poire"  # ["poire", "banane", "orange"]
```

**Ajout d'éléments** :

```python
fruits = ["pomme", "banane"]
fruits.append("orange")           # ["pomme", "banane", "orange"]
fruits.insert(1, "kiwi")          # ["pomme", "kiwi", "banane", "orange"]
fruits.extend(["mangue", "ananas"])  # Ajoute plusieurs éléments
```

**Suppression d'éléments** :

```python
fruits = ["pomme", "banane", "orange"]
fruits.remove("banane")  # Supprime par valeur
fruits.pop(0)           # Supprime par index et renvoie l'élément
del fruits[0]           # Supprime par index
```

**Opérations sur les listes** :

```python
nombres = [3, 1, 4, 1, 5, 9, 2, 6]
longueur = len(nombres)              # 8
tri = sorted(nombres)                 # [1, 1, 2, 3, 4, 5, 6, 9]
inverse = nombres[::-1]                # [6, 2, 9, 5, 1, 4, 1, 3]
compte = nombres.count(1)             # 2
index = nombres.index(4)              # 3
```

<Callout type="tip">
`sorted()` renvoie une nouvelle liste triée, tandis que `list.sort()` trie la liste en place (modifie l'originale).
</Callout>

### Tuples

Les tuples sont des collections ordonnées et immuables.

**Création de tuples** :

```python
coordonnees = (10, 20)
unique = (1,)  # Tuple avec un seul élément (virgule obligatoire)
sans_parentheses = 1, 2, 3  # Tuple implicite
```

**Accès aux éléments** :

```python
coordonnees = (10, 20)
x = coordonnees[0]  # 10
y = coordonnees[1]  # 20
```

**Immutabilité** :

```python
coordonnees = (10, 20)
coordonnees[0] = 15  # TypeError: 'tuple' object does not support item assignment
```

**Déballage (unpacking)** :

```python
coordonnees = (10, 20)
x, y = coordonnees  # x=10, y=20
```

<Callout type="info">
Les tuples sont plus légers que les listes et garantissent que les données ne seront pas modifiées accidentellement. Utilisez-les pour des données constantes.
</Callout>

### Dictionnaires

Les dictionnaires sont des collections de paires clé-valeur non ordonnées.

**Création de dictionnaires** :

```python
personne = {
    "nom": "Alice",
    "age": 25,
    "ville": "Paris"
}
vide = {}
```

**Accès aux valeurs** :

```python
personne = {"nom": "Alice", "age": 25}
nom = personne["nom"]           # "Alice"
age = personne.get("age")       # 25
inconnu = personne.get("pays", "Inconnu")  # "Inconnu" (valeur par défaut)
```

**Modification et ajout** :

```python
personne = {"nom": "Alice", "age": 25}
personne["age"] = 26         # Modification
personne["pays"] = "France"  # Ajout
personne.update({"ville": "Paris", "code": 75001})  # Ajout multiple
```

**Suppression** :

```python
personne = {"nom": "Alice", "age": 25, "ville": "Paris"}
del personne["age"]           # Supprime la clé
valeur = personne.pop("ville")  # Supprime et renvoie la valeur
```

**Itération** :

```python
personne = {"nom": "Alice", "age": 25, "ville": "Paris"}

for cle in personne:
    print(cle)  # "nom", "age", "ville"

for valeur in personne.values():
    print(valeur)  # "Alice", 25, "Paris"

for cle, valeur in personne.items():
    print(f"{cle}: {valeur}")  # "nom: Alice", "age: 25", "ville: Paris"
```

### Sets

Les sets sont des collections non ordonnées d'éléments uniques.

**Création de sets** :

```python
nombres = {1, 2, 3, 4, 5}
lettre = set("hello")  # {'h', 'e', 'l', 'o'} (uniques)
vide = set()
```

**Opérations sur les sets** :

```python
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

union = set1 | set2           # {1, 2, 3, 4, 5, 6}
intersection = set1 & set2    # {3, 4}
difference = set1 - set2     # {1, 2}
difference_sym = set1 ^ set2 # {1, 2, 5, 6}
```

**Méthodes** :

```python
nombres = {1, 2, 3}
nombres.add(4)         # {1, 2, 3, 4}
nombres.remove(2)      # {1, 3, 4}
nombres.discard(5)     # Ne lève pas d'erreur si l'élément n'existe pas
contient = 3 in nombres  # True
```

<Callout type="info">
Les sets sont utiles pour éliminer les doublons et effectuer des opérations d'ensemble (union, intersection) efficacement.
</Callout>

### Algorithmes de base

**Recherche linéaire** :

```python
def recherche_lineaire(liste, element):
    for i, valeur in enumerate(liste):
        if valeur == element:
            return i
    return -1  # Non trouvé

nombres = [3, 1, 4, 1, 5, 9, 2, 6]
index = recherche_lineaire(nombres, 5)  # 4
```

**Tri à bulles (bubble sort)** :

```python
def tri_bulles(liste):
    n = len(liste)
    for i in range(n):
        for j in range(0, n - i - 1):
            if liste[j] > liste[j + 1]:
                liste[j], liste[j + 1] = liste[j + 1], liste[j]
    return liste

nombres = [64, 34, 25, 12, 22, 11, 90]
tri_bulles(nombres)  # [11, 12, 22, 25, 34, 64, 90]
```

<Callout type="warn">
Le tri à bulles est inefficace pour les grandes listes. Utilisez `sorted()` ou `list.sort()` pour des performances optimales.
</Callout>

### Compréhensions avancées

**Dict comprehension** :

```python
carres = {x: x ** 2 for x in range(5)}  # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
pairs = {x: x for x in range(10) if x % 2 == 0}  # {0: 0, 2: 2, 4: 4, 6: 6, 8: 8}
```

**Set comprehension** :

```python
carres_pairs = {x ** 2 for x in range(10) if x % 2 == 0}  # {0, 4, 16, 36, 64}
```

### Choix de la structure de données

- **Liste** : collection ordonnée, modifiable, accès par index.
- **Tuple** : collection ordonnée, immuable, données constantes.
- **Dictionnaire** : collection clé-valeur, accès rapide par clé.
- **Set** : collection non ordonnée, éléments uniques, opérations d'ensemble.

## Erreurs fréquentes

**Index hors limites (IndexError)**

```python
fruits = ["pomme", "banane"]
print(fruits[2])  # IndexError: list index out of range
```

L'index 2 n'existe pas (les indices vont de 0 à len-1).

<Callout type="warn">
```python
fruits = ["pomme", "banane"]
if len(fruits) > 2:
    print(fruits[2])  # Vérifiez d'abord la longueur
```
Toujours vérifier que l'index existe avant d'y accéder.
</Callout>

**Clé manquante dans un dictionnaire (KeyError)**

```python
personne = {"nom": "Alice"}
print(personne["age"])  # KeyError: 'age'
```

La clé "age" n'existe pas dans le dictionnaire.

<Callout type="warn">
```python
personne = {"nom": "Alice"}
age = personne.get("age", "Inconnu")  # Utilisez get() avec valeur par défaut
```
Utilisez `get()` avec une valeur par défaut pour éviter KeyError.
</Callout>

**Modifier un tuple**

```python
coordonnees = (10, 20)
coordonnees[0] = 15  # TypeError: 'tuple' object does not support item assignment
```

Les tuples sont immuables.

<Callout type="warn">
```python
coordonnees = (10, 20)
coordonnees = (15, 20)  # Créez un nouveau tuple
```
Pour "modifier" un tuple, créez-en un nouveau avec les modifications souhaitées.
</Callout>

**Utiliser un objet mutable comme clé de dictionnaire**

```python
ma_liste = [1, 2, 3]
mon_dict = {ma_liste: "valeur"}  # TypeError: unhashable type: 'list'
```

Les clés de dictionnaire doivent être immuables (hashable).

<Callout type="warn">
```python
mon_tuple = (1, 2, 3)
mon_dict = {mon_tuple: "valeur"}  # Correct : les tuples sont hashables
```
Utilisez des tuples ou des immuables comme clés de dictionnaire.
</Callout>

<Exercise n="5.8" title="Défi : Gestionnaire de contacts">
Créez un gestionnaire de contacts avec les fonctionnalités suivantes :

1. Ajouter un contact (nom, téléphone, email)
2. Rechercher un contact par nom
3. Supprimer un contact
4. Lister tous les contacts
5. Stocker les contacts dans un dictionnaire

Utilisez des fonctions pour chaque opération.
</Exercise>

<Solution>
```python
contacts = {}

def ajouter_contact(nom, telephone, email):
    contacts[nom] = {"telephone": telephone, "email": email}
    print(f"Contact {nom} ajouté")

def rechercher_contact(nom):
    if nom in contacts:
        return contacts[nom]
    return None

def supprimer_contact(nom):
    if nom in contacts:
        del contacts[nom]
        print(f"Contact {nom} supprimé")
    else:
        print(f"Contact {nom} non trouvé")

def lister_contacts():
    for nom, infos in contacts.items():
        print(f"{nom} : {infos['telephone']}, {infos['email']}")

# Tests
ajouter_contact("Alice", "0123456789", "alice@email.com")
ajouter_contact("Bob", "0987654321", "bob@email.com")

print("Contacts :")
lister_contacts()

print("\nRecherche Alice :")
print(rechercher_contact("Alice"))

print("\nSuppression Bob :")
supprimer_contact("Bob")

print("\nContacts après suppression :")
lister_contacts()
```
</Solution>

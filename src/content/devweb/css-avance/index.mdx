# CSS — Avancé

Ce module explore les fonctionnalités avancées de CSS qui permettent de créer des interfaces dynamiques, maintenables et adaptables. Il explique les variables CSS (custom properties) pour la réutilisabilité et les thèmes, les pseudo-classes et pseudo-éléments pour des interactions riches, les transitions et animations pour le mouvement, et les méthodologies d'organisation comme BEM pour la maintenabilité du code. À l'issue de ce module, vous serez capable de créer un mini design system cohérent avec un thème clair/sombre et des animations subtiles.

## Objectifs

- Définir et utiliser des variables CSS (custom properties) pour la réutilisabilité.
- Comprendre les pseudo-classes (`:hover`, `:focus`, `:nth-child`) et pseudo-éléments (`::before`, `::after`).
- Créer des transitions CSS pour des changements d'état fluides.
- Créer des animations CSS avec keyframes.
- Organiser le CSS avec une méthodologie (BEM).
- Implémenter un thème clair/sombre avec les préférences utilisateur.
- Créer un mini design system cohérent (variables, composants, documentation).

## Prérequis

- CSS — Bases (sélecteurs, cascade, modèle de boîte)
- CSS — Mise en page (Flexbox, Grid, media queries)

## Cours

### Variables CSS

Les variables CSS (custom properties) permettent de stocker des valeurs réutilisables dans le CSS. Elles sont définies avec le préfixe `--` et utilisées avec la fonction `var()`. Contrairement aux préprocesseurs (Sass, Less), les variables CSS sont natives, dynamiques, et peuvent être modifiées en JavaScript.

**Déclaration** : les variables sont généralement déclarées dans `:root` pour être globales, ou dans un sélecteur spécifique pour être locales.

```css
:root {
  --color-primary: #6366f1;
  --color-text: #333;
  --spacing-unit: 8px;
  --font-size-base: 16px;
}

.button {
  background-color: var(--color-primary);
  color: white;
  padding: calc(var(--spacing-unit) * 2) calc(var(--spacing-unit) * 3);
}
```

**Utilisation** : la fonction `var()` accepte une valeur de fallback si la variable n'est pas définie.

```css
.button {
  background-color: var(--color-primary, blue);
}
```

**Héritage** : les variables CSS sont héritées par les descendants, comme les propriétés CSS ordinaires.

```css
:root {
  --color-text: #333;
}

body {
  color: var(--color-text);
}

p {
  /* Hérite de --color-text depuis :root via body */
}
```

**Modification en JavaScript** : les variables CSS peuvent être modifiées dynamiquement via JavaScript, ce qui permet d'implémenter des thèmes dynamiques.

```javascript
document.documentElement.style.setProperty('--color-primary', '#ff0000');
```

<Callout type="tip">
Utilisez des variables CSS pour les valeurs qui sont susceptibles de changer (couleurs, espacements, typographie). Cela facilite la maintenance et permet d'implémenter des thèmes sans dupliquer le CSS.
</Callout>

### Pseudo-classes

Les pseudo-classes sélectionnent des éléments dans un état particulier, qui n'est pas représenté dans l'arbre du DOM. Elles commencent par deux-points (`:`).

**` :hover`** : élément survolé par le curseur.

```css
.button:hover {
  background-color: #5558e3;
}
```

**` :focus`** : élément qui a le focus (clavier ou souris).

```css
input:focus {
  outline: 2px solid var(--color-primary);
}
```

**` :active`** : élément en cours d'activation (bouton enfoncé).

```css
.button:active {
  transform: scale(0.98);
}
```

**` :visited`** : lien déjà visité par l'utilisateur.

```css
a:visited {
  color: purple;
}
```

**` :first-child`** : premier enfant de son parent.

```css
ul li:first-child {
  font-weight: bold;
}
```

**` :last-child`** : dernier enfant de son parent.

```css
ul li:last-child {
  margin-bottom: 0;
}
```

**` :nth-child(n)`** : nième enfant de son parent. `n` peut être un nombre, une formule (`2n` pour pairs, `2n+1` pour impairs), ou des mots-clés (`odd`, `even`).

```css
/* Lignes paires d'un tableau */
tr:nth-child(even) {
  background-color: #f5f5f5;
}

/* Troisième élément */
li:nth-child(3) {
  color: red;
}

/* Tous les 3 éléments */
li:nth-child(3n) {
  font-weight: bold;
}
```

**` :not(selector)`** : éléments qui ne correspondent pas au sélecteur.

```css
:not(.button) {
  cursor: default;
}
```

<Callout type="info">
Les pseudo-classes peuvent être chaînées : `a:hover:not(.disabled)` sélectionne les liens survolés qui n'ont pas la classe disabled.
</Callout>

### Pseudo-éléments

Les pseudo-éléments sélectionnent une partie d'un élément qui n'existe pas dans l'arbre du DOM. Ils commencent par deux points doubles (`::`).

**` ::before`** : pseudo-élément avant le contenu de l'élément.

```css
.button::before {
  content: "→ ";
}
```

**` ::after`** : pseudo-élément après le contenu de l'élément.

```css
a.external::after {
  content: " ↗";
}
```

**` ::first-letter`** : première lettre du texte.

```css
p::first-letter {
  font-size: 2rem;
  font-weight: bold;
}
```

**` ::first-line`** : première ligne du texte.

```css
p::first-line {
  font-weight: bold;
}
```

**` ::placeholder`** : texte placeholder d'un champ de formulaire.

```css
input::placeholder {
  color: #999;
}
```

<Callout type="tip">
Les pseudo-éléments doivent avoir la propriété `content` (même vide `content: ""`) pour être rendus. Ils peuvent être stylisés comme des éléments ordinaires (padding, margin, background, etc.).
</Callout>

### Transitions

Les transitions CSS permettent de modifier progressivement une propriété d'un état à un autre, créant des animations fluides lors des changements d'état (hover, focus, etc.).

**Syntaxe de base** : la propriété `transition` est un raccourci pour `transition-property`, `transition-duration`, `transition-timing-function`, et `transition-delay`.

```css
.button {
  background-color: var(--color-primary);
  transition: background-color 150ms ease;
}

.button:hover {
  background-color: #5558e3;
}
```

**Propriétés individuelles** :

```css
.button {
  transition-property: background-color, transform;
  transition-duration: 150ms;
  transition-timing-function: ease;
  transition-delay: 0ms;
}
```

**Fonctions de timing** : définissent la courbe d'accélération de la transition.

- `linear` : vitesse constante.
- `ease` : départ lent, accélération, fin lente (par défaut).
- `ease-in` : départ lent, fin rapide.
- `ease-out` : départ rapide, fin lente.
- `ease-in-out` : départ lent, accélération, fin lente (plus marqué que ease).
- `cubic-bezier(x1, y1, x2, y2)` : courbe personnalisée.

```css
.button {
  transition: transform 150ms cubic-bezier(0.16, 1, 0.3, 1);
}
```

**Transitions multiples** : séparez les transitions par des virgules.

```css
.button {
  transition:
    background-color 150ms ease,
    transform 150ms cubic-bezier(0.16, 1, 0.3, 1),
    box-shadow 150ms ease;
}
```

<Callout type="warn">
Les transitions ne fonctionnent que sur les propriétés animables (color, background-color, transform, opacity, etc.). Elles ne fonctionnent pas sur les propriétés discrètes (display, visibility, z-index).
</Callout>

### Animations

Les animations CSS permettent de créer des animations plus complexes que les transitions, avec des keyframes qui définissent des étapes intermédiaires. Contrairement aux transitions, les animations peuvent boucler et être contrôlées (pause, play, reverse).

**Déclaration d'animation** : la propriété `animation` est un raccourci pour `animation-name`, `animation-duration`, `animation-timing-function`, `animation-delay`, `animation-iteration-count`, `animation-direction`, `animation-fill-mode`, et `animation-play-state`.

```css
.button {
  animation: pulse 2s ease-in-out infinite;
}
```

**Keyframes** : définissent les étapes de l'animation.

```css
@keyframes pulse {
  0% {
    transform: scale(1);
  }
  50% {
    transform: scale(1.05);
  }
  100% {
    transform: scale(1);
  }
}
```

**Propriétés individuelles** :

```css
.button {
  animation-name: pulse;
  animation-duration: 2s;
  animation-timing-function: ease-in-out;
  animation-delay: 0s;
  animation-iteration-count: infinite;
  animation-direction: normal;
  animation-fill-mode: none;
  animation-play-state: running;
}
```

**Nombre d'itérations** : `animation-iteration-count` peut être un nombre ou `infinite`.

```css
/* Animation une seule fois */
.button {
  animation: slide-in 300ms ease 1;
}

/* Animation en boucle */
.loading {
  animation: spin 1s linear infinite;
}
```

**Direction** : `animation-direction` définit le sens de l'animation.

- `normal` : de début à fin, puis recommence.
- `reverse` : de fin à début, puis recommence.
- `alternate` : alterne entre normal et reverse.
- `alternate-reverse` : alterne entre reverse et normal.

```css
.pulse {
  animation: pulse 2s ease-in-out infinite alternate;
}
```

<Callout type="tip">
Pour des performances optimales, animez uniquement les propriétés `transform` et `opacity`. Ces propriétés ne déclenchent pas de recalcul de layout (reflow), seulement de composition (repaint), ce qui est beaucoup plus performant.
</Callout>

### Organisation du CSS (BEM)

BEM (Block Element Modifier) est une méthodologie de nommage des classes CSS qui favorise la réutilisabilité et la maintenabilité. Elle repose sur trois concepts :

**Block** : composant autonome et réutilisable (ex: `card`, `button`, `nav`).

```css
.card { }
.button { }
```

**Element** : partie d'un block, dépendante du block (notée avec deux underscores `__`).

```css
.card__title { }
.card__content { }
.button__icon { }
```

**Modifier** : variante d'un block ou d'un element (notée avec deux tirets `--`).

```css
.button--primary { }
.button--secondary { }
.card--featured { }
.card__title--large { }
```

Exemple complet :

```html
<div class="card card--featured">
  <h2 class="card__title card__title--large">Titre</h2>
  <p class="card__content">Contenu</p>
  <button class="card__button card__button--primary">Action</button>
</div>
```

```css
.card {
  padding: 24px;
  border: 1px solid #e0e0e0;
  border-radius: 8px;
}

.card--featured {
  border-color: var(--color-primary);
}

.card__title {
  margin: 0 0 16px;
}

.card__title--large {
  font-size: 1.5rem;
}

.card__content {
  color: var(--color-text-muted);
}

.card__button {
  margin-top: 16px;
}

.card__button--primary {
  background-color: var(--color-primary);
  color: white;
}
```

<Callout type="info">
BEM évite la spécificité excessive : les sélecteurs restent simples (`.card__title` au lieu de `.card .title`), ce qui facilite la surcharge des styles et la maintenance.
</Callout>

### Architecture de fichiers

Pour les projets de taille moyenne à grande, organisez le CSS en plusieurs fichiers selon l'approche component-based ou ITCSS (Inverted Triangle CSS).

**Approche component-based** :

```
styles/
├── tokens.css          /* Variables globales */
├── reset.css           /* Reset CSS */
├── base.css            /* Styles de base (body, typographie) */
├── components/
│   ├── button.css
│   ├── card.css
│   └── form.css
├── layout/
│   ├── header.css
│   ├── footer.css
│   └── grid.css
└── utilities.css       /* Classes utilitaires */
```

**ITCSS** : organise le CSS par ordre de spécificité croissante (du plus général au plus spécifique).

1. Settings (variables)
2. Tools (mixins, fonctions)
3. Generic (reset, normalize)
4. Base (éléments HTML de base)
5. Objects (classes sans style, ex: `.container`)
6. Components (composants UI)
7. Utilities (classes utilitaires)
8. Trumps (overrides, ex: `!important`)

### Thème clair/sombre

Les variables CSS facilitent l'implémentation de thèmes. Pour un thème clair/sombre, définissez les variables de couleur dans `:root` et overridez-les dans une media query pour `prefers-color-scheme: dark`.

```css
:root {
  --color-background: #ffffff;
  --color-text: #333;
  --color-primary: #6366f1;
  --color-border: #e0e0e0;
}

@media (prefers-color-scheme: dark) {
  :root {
    --color-background: #1a1a1a;
    --color-text: #ededf0;
    --color-primary: #818cf8;
    --color-border: #333;
  }
}

body {
  background-color: var(--color-background);
  color: var(--color-text);
}
```

Pour un basculement manuel (bouton toggle), utilisez une classe sur `html` ou `body`.

```css
:root {
  --color-background: #ffffff;
  --color-text: #333;
}

body.dark {
  --color-background: #1a1a1a;
  --color-text: #ededf0;
}
```

```javascript
// JavaScript pour basculer le thème
document.body.classList.toggle('dark');
```

<Callout type="tip">
Testez toujours vos thèmes pour l'accessibilité. Le contraste entre le texte et l'arrière-plan doit être suffisant (ratio de contraste AA minimum 4.5:1 pour le texte normal, 3:1 pour le texte large).
</Callout>

## Erreurs fréquentes

**Oublier le content sur les pseudo-éléments**

```css
.button::before {
  color: red;
}
```

Le pseudo-élément n'est pas rendu car la propriété `content` est manquante.

<Callout type="warn">
```css
.button::before {
  content: "";
  color: red;
}
```
Toujours inclure `content` (même vide) sur les pseudo-éléments `::before` et `::after`.
</Callout>

**Animer des propriétés non animables**

```css
.button {
  transition: display 150ms ease;
}

.button:hover {
  display: none;
}
```

La transition ne fonctionne pas car `display` n'est pas une propriété animable.

<Callout type="warn">
```css
.button {
  transition: opacity 150ms ease, transform 150ms ease;
}

.button:hover {
  opacity: 0;
  transform: scale(0.95);
}
```
Animez uniquement les propriétés animables : opacity, transform, color, background-color, etc. Pour masquer un élément avec animation, utilisez opacity + visibility, pas display.
</Callout>

**Noms de classes non BEM**

```css
.card .title { }
.card .button.primary { }
```

Les sélecteurs sont spécifiques et dépendent de la structure HTML. Difficile à maintenir et à surcharger.

<Callout type="warn">
```css
.card__title { }
.card__button--primary { }
```
Utilisez BEM pour des sélecteurs simples et réutilisables. Block__Element--Modifier assure une spécificité constante et une relation claire.
</Callout>

**Variables non héritées comme attendu**

```css
:root {
  --spacing: 16px;
}

.card {
  margin: var(--spacing);
}

.card__title {
  /* Expected: margin: var(--spacing) does not work */
}
```

Les variables ne sont pas automatiquement héritées par les propriétés qui n'héritent pas normalement (margin, padding, etc.).

<Callout type="warn">
```css
:root {
  --spacing: 16px;
}

.card {
  margin: var(--spacing);
}

.card__title {
  margin: var(--spacing); /* Utilise la variable explicitement */
}
```
Les variables sont héritées comme des valeurs, mais chaque propriété doit utiliser `var()` explicitement. Les variables ne remplacent pas le mécanisme d'héritage des propriétés.
</Callout>

**Animation qui ne boucle pas comme prévu**

```css
.loading {
  animation: spin 1s linear;
}
```

L'animation ne boucle pas car `animation-iteration-count` n'est pas spécifié (par défaut 1).

<Callout type="warn">
```css
.loading {
  animation: spin 1s linear infinite;
}
```
Spécifiez `infinite` pour une animation en boucle, ou un nombre précis pour un nombre d'itérations déterminé.
</Callout>

## Livrable

Créez un mini design system cohérent. Le design system doit inclure :

**Variables CSS obligatoires**
- Couleurs (primary, secondary, neutral palette)
- Espacements (échelle de 4px à 64px)
- Typographie (font-sizes, line-heights, font-weights)
- Bordures (radius, width)
- Ombres (small, medium, large)
- Transitions (fast, base, slow)

**Composants BEM obligatoires**
- Button (au moins 3 variants)
- Card (au moins 1 variant)
- Input (avec states focus et error)
- Badge (au moins 2 variants)

**Thème obligatoire**
- Thème clair par défaut
- Thème sombre avec media query `prefers-color-scheme: dark`
- Transitions fluides entre les thèmes

**Critères d'évaluation**
- [ ] Variables CSS bien organisées et documentées
- [ ] Composants nommés selon BEM
- [ ] Utilisation des variables CSS dans tous les composants
- [ ] Thème sombre fonctionnel
- [ ] Transitions sur les interactions (hover, focus)
- [ ] Documentation en commentaires
- [ ] Design cohérent et professionnel

**Pistes d'extension**
- Ajoutez plus de composants (Modal, Alert, Tabs)
- Créez des utilitaires CSS (text-center, flex, grid)
- Implémentez un basculement manuel du thème
- Ajoutez des animations aux composants
- Créez une page de documentation HTML du design system

# CSS — Bases

Ce module introduit CSS (Cascading Style Sheets), le langage qui définit la présentation des documents HTML. Il explique le fonctionnement de la cascade, la spécificité des sélecteurs, l'héritage des styles, le modèle de boîte, les unités de mesure, les couleurs et la typographie. Ces concepts fondamentaux sont indispensables pour comprendre comment les styles sont appliqués et résoudre les conflits de styles. À l'issue de ce module, vous serez capable de styliser un document HTML avec CSS, en particulier de transformer le CV créé dans le module précédent en un document visuellement soigné.

## Objectifs

- Comprendre le mécanisme de cascade et la résolution des conflits de styles.
- Utiliser les sélecteurs CSS (élément, classe, id, attribut, pseudo-classe).
- Calculer la spécificité d'un sélecteur et prédire quel style sera appliqué.
- Comprendre l'héritage des propriétés et savoir quelles propriétés sont héritées.
- Maîtriser le modèle de boîte (content, padding, border, margin).
- Choisir les unités de mesure appropriées (px, em, rem, %, vw, vh).
- Définir des couleurs avec les différents formats (hex, rgb, hsl, mots-clés).
- Appliquer des styles typographiques (taille, graisse, interlignage, espacement).

## Prérequis

- Fondamentaux du web (structure des fichiers, liens)
- HTML — Structure (éléments sémantiques, DOM)

## Cours

### Introduction à CSS

CSS (Cascading Style Sheets) est un langage de feuilles de style utilisé pour décrire la présentation des documents écrits en HTML. CSS sépare la structure (HTML) de la présentation (CSS), ce qui facilite la maintenance et permet de réutiliser les styles sur plusieurs pages.

<Callout type="info">
La séparation structure/présentation est un principe fondamental du développement web moderne. Elle permet de modifier l'apparence d'un site sans toucher à son contenu, et inversement.
</Callout>

Il existe trois façons d'appliquer du CSS à un document HTML :

**CSS externe** (recommandé) : le CSS est dans un fichier séparé, lié via l'élément `link`.

```html
<link rel="stylesheet" href="styles.css">
```

**CSS interne** : le CSS est dans un élément `style` dans le `head`.

```html
<style>
  body { font-family: sans-serif; }
</style>
```

**CSS en ligne** : le CSS est dans un attribut `style` sur un élément.

```html
<p style="color: red;">Texte rouge</p>
```

Le CSS externe est préférable car il permet la réutilisation sur plusieurs pages, sépare clairement les préoccupations, et facilite la mise en cache par le navigateur.

### Syntaxe CSS

Une règle CSS se compose d'un sélecteur et d'un bloc de déclarations. Le sélecteur indique à quels éléments appliquer les styles. Le bloc de déclarations contient une ou plusieurs déclarations, chacune composée d'une propriété et d'une valeur.

```css
selecteur {
  propriete: valeur;
  propriete: valeur;
}
```

Exemple :

```css
h1 {
  color: #333;
  font-size: 2rem;
  font-weight: 600;
}
```

Les conventions de style courantes :

- Les propriétés en kebab-case (`font-size`, pas `fontSize`).
- Les valeurs terminées par un point-virgule.
- L'indentation cohérente (2 ou 4 espaces).
- Une déclaration par ligne pour la lisibilité.

<Callout type="tip">
Le point-virgule après la dernière déclaration est optionnel mais recommandé. Il évite les erreurs si une nouvelle déclaration est ajoutée par la suite.
</Callout>

### Sélecteurs CSS

Les sélecteurs identifient les éléments HTML auxquels appliquer les styles.

**Sélecteur d'élément** : sélectionne tous les éléments d'un type.

```css
p { color: #333; }
a { text-decoration: none; }
```

**Sélecteur de classe** : sélectionne les éléments avec un attribut `class` spécifique. Le préfixe `.` indique une classe.

```css
.highlight { background-color: yellow; }
.button { padding: 10px 20px; }
```

```html
<p class="highlight">Texte surligné</p>
<button class="button">Cliquez</button>
```

Un élément peut avoir plusieurs classes, séparées par des espaces.

```html
<div class="card highlight">...</div>
```

**Sélecteur d'identifiant** : sélectionne l'élément avec un attribut `id` spécifique. Le préfixe `#` indique un identifiant. Un id doit être unique dans le document.

```css
#header { background-color: #333; }
#main-content { max-width: 1200px; }
```

```html
<header id="header">...</header>
```

**Sélecteur descendant** : sélectionne les éléments qui sont descendants d'un autre élément. L'espace indique la relation descendant.

```css
article p { line-height: 1.6; }
nav a { color: white; }
```

```html
<article>
  <p>Ce paragraphe est stylisé</p>
</article>
```

**Sélecteur d'enfant direct** : sélectionne les éléments qui sont enfants directs (pas petits-enfants). Le symbole `>` indique la relation parent-enfant.

```css
ul > li { margin-bottom: 8px; }
```

```html
<ul>
  <li>Cet élément est stylisé</li>
  <li>
    <ul>
      <li>Cet élément n'est pas stylisé (petit-enfant)</li>
    </ul>
  </li>
</ul>
```

**Sélecteur d'attribut** : sélectionne les éléments avec un attribut spécifique ou une valeur d'attribut.

```css
[href] { color: blue; }
[type="email"] { border: 1px solid #ccc; }
[href^="https"] { font-weight: bold; }
```

**Sélecteur de pseudo-classe** : sélectionne les éléments dans un état particulier.

```css
a:hover { color: red; }
input:focus { outline: 2px solid blue; }
li:first-child { font-weight: bold; }
```

**Sélecteur de pseudo-élément** : sélectionne une partie d'un élément.

```css
p::first-letter { font-size: 2rem; }
a::after { content: " →"; }
```

### Cascade et spécificité

La cascade est le mécanisme par lequel le navigateur détermine quelles règles CSS appliquer lorsque plusieurs règles ciblent le même élément. La cascade prend en compte trois facteurs : l'origine, la spécificité, et l'ordre de déclaration.

**Origine** : les styles sont appliqués dans l'ordre suivant (du moins prioritaire au plus prioritaire) :

1. Styles utilisateur (navigateur par défaut)
2. Styles auteur (votre CSS)
3. Styles utilisateur (préférences utilisateur, ex: taille de police)
4. Styles avec `!important` (à éviter en général)

**Spécificité** : chaque sélecteur a un poids qui détermine sa priorité. La spécificité est calculée comme un triplet (A, B, C) :

- A : nombre d'identifiants (id)
- B : nombre de classes, pseudo-classes, attributs
- C : nombre d'éléments, pseudo-éléments

```css
/* Spécificité (0, 0, 1) */
p { color: black; }

/* Spécificité (0, 1, 0) */
.highlight { color: yellow; }

/* Spécificité (1, 0, 0) */
#header { color: red; }

/* Spécificité (0, 1, 1) */
p.highlight { color: blue; }

/* Spécificité (1, 1, 0) */
#header.highlight { color: green; }
```

Un sélecteur avec une spécificité plus élevée l'emporte toujours, quel que soit l'ordre de déclaration.

<Callout type="tip">
Pour éviter les conflits de spécificité, utilisez des sélecteurs simples et évitez d'imbriquer excessivement les sélecteurs. Préférez les classes aux identifiants pour la réutilisabilité.
</Callout>

**Ordre de déclaration** : si deux règles ont la même spécificité, la dernière déclarée l'emporte.

```css
p { color: black; }
p { color: red; } /* L'emporte, même spécificité */
```

### Héritage

Certaines propriétés CSS sont héritées par les éléments descendants, d'autres non. L'héritage permet de définir des styles globaux qui s'appliquent automatiquement à tout le document.

**Propriétés héritées** (exemples) :

- `color` : couleur du texte
- `font-family` : police de caractères
- `font-size` : taille de police
- `line-height` : interlignage
- `text-align` : alignement du texte

```css
body {
  color: #333;
  font-family: sans-serif;
}
/* Tous les descendants héritent de la couleur et de la police */
```

**Propriétés non héritées** (exemples) :

- `margin`, `padding` : espacement
- `border` : bordures
- `width`, `height` : dimensions
- `background` : arrière-plan

```css
div { padding: 20px; }
/* Les éléments enfants n'héritent pas du padding */
```

Vous pouvez forcer l'héritage avec la valeur `inherit` ou l'empêcher avec `initial`.

```css
p { color: inherit; }
div { padding: initial; }
```

### Modèle de boîte

Le modèle de boîte (box model) décrit comment chaque élément HTML est représenté comme une boîte rectangulaire. Cette boîte se compose de quatre zones, de l'intérieur vers l'extérieur :

1. **Content** : le contenu de l'élément (texte, image).
2. **Padding** : l'espace entre le contenu et la bordure.
3. **Border** : la bordure autour du padding.
4. **Margin** : l'espace extérieur à la bordure (sépare l'élément des autres).

```css
.box {
  width: 300px;
  padding: 20px;
  border: 2px solid #333;
  margin: 10px;
}
```

La largeur totale de l'élément est : `width + padding-left + padding-right + border-left + border-right + margin-left + margin-right`.

Par défaut, CSS utilise le modèle `content-box` : la propriété `width` définit uniquement la largeur du contenu. Pour que `width` inclue padding et border, utilisez `box-sizing: border-box`.

```css
* {
  box-sizing: border-box;
}
```

Cette règle est généralement appliquée au début de la feuille de style pour simplifier les calculs de largeur.

<Callout type="info">
Avec `border-box`, `width: 300px` signifie que la largeur totale de l'élément (content + padding + border) est de 300px. C'est généralement plus intuitif que `content-box`.
</Callout>

### Unités de mesure

CSS propose plusieurs unités de mesure pour les longueurs, les tailles de police, et d'autres valeurs dimensionnelles.

**Unités absolues** : ont une taille fixe, indépendante du contexte.

- `px` : pixel (1/96ème de pouce, l'unité la plus courante).
- `mm`, `cm` : millimètres, centimètres.
- `in` : pouces (1 in = 96 px).
- `pt` : points (1 pt = 1/72 in).

```css
p { font-size: 16px; }
div { width: 300px; }
```

**Unités relatives** : leur taille dépend du contexte.

- `em` : relatif à la taille de police de l'élément parent.
- `rem` : relatif à la taille de police de l'élément racine (html).
- `%` : relatif à la taille de l'élément parent.
- `vw` : 1% de la largeur de la fenêtre (viewport width).
- `vh` : 1% de la hauteur de la fenêtre (viewport height).

```css
html { font-size: 16px; }
p { font-size: 1rem; } /* 16px */
h1 { font-size: 2rem; } /* 32px */
div { width: 50%; } /* 50% de la largeur du parent */
```

<Callout type="tip">
Préférez `rem` pour les tailles de police (cohérence globale) et `em` pour les marges/padding (proportionnels à la taille de police locale). Utilisez `%` pour les largeurs (responsive) et `px` pour les bordures (précision).
</Callout>

### Couleurs

CSS propose plusieurs formats pour définir les couleurs.

**Mots-clés** : noms de couleurs prédéfinis.

```css
color: red;
background-color: blue;
```

**Hexadécimal** : notation hexadécimale RGB. La forme courte (#RGB) est équivalente à la forme longue (#RRGGBB).

```css
color: #ff0000; /* rouge */
color: #f00; /* rouge, forme courte */
color: #333; /* gris foncé */
```

**RGB** : notation fonctionnelle avec trois valeurs (rouge, vert, bleu) de 0 à 255.

```css
color: rgb(255, 0, 0); /* rouge */
color: rgb(51, 51, 51); /* gris foncé */
```

**RGBA** : comme RGB avec un canal alpha (transparence) de 0 à 1.

```css
color: rgba(255, 0, 0, 0.5); /* rouge semi-transparent */
background-color: rgba(0, 0, 0, 0.8); /* noir semi-transparent */
```

**HSL** : teinte (0-360), saturation (0-100%), luminosité (0-100%).

```css
color: hsl(0, 100%, 50%); /* rouge */
color: hsl(220, 15%, 20%); /* gris foncé bleuté */
```

**HSLA** : comme HSL avec un canal alpha.

```css
color: hsla(0, 100%, 50%, 0.5);
```

<Callout type="tip">
HSL est souvent plus intuitif pour ajuster une couleur : changer la teinte (H) change la couleur, changer la saturation (S) change l'intensité, changer la luminosité (L) change la clarté.
</Callout>

### Typographie

CSS permet de contrôler tous les aspects de la typographie.

**Famille de police** : définie avec `font-family`. Liste de polices séparées par des virgules, en ordre de préférence. Le navigateur utilise la première police disponible.

```css
body {
  font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
}
```

Les catégories de polices génériques (fallback) :

- `sans-serif` : sans empattements (Arial, Helvetica, Verdana).
- `serif` : avec empattements (Times New Roman, Georgia).
- `monospace` : à chasse fixe (Courier New, monospace).
- `cursive` : style manuscrit.
- `fantasy` : décoratif.

**Taille de police** : définie avec `font-size`. Les unités relatives (rem, em) sont préférées pour l'accessibilité (l'utilisateur peut redimensionner la police de base).

```css
html { font-size: 16px; }
h1 { font-size: 2rem; } /* 32px */
p { font-size: 1rem; } /* 16px */
small { font-size: 0.875rem; } /* 14px */
```

**Graisse de police** : définie avec `font-weight`. Les valeurs sont `normal` (400), `bold` (700), ou des valeurs numériques de 100 à 900.

```css
h1 { font-weight: 700; }
strong { font-weight: bold; }
```

**Style de police** : définie avec `font-style` (`normal`, `italic`, `oblique`).

```css
em { font-style: italic; }
```

**Interlignage** : défini avec `line-height`. Une valeur sans unité est relative à la taille de police (recommandé).

```css
p { line-height: 1.6; } /* 1.6 fois la taille de police */
```

**Espacement des lettres** : défini avec `letter-spacing`.

```css
h1 { letter-spacing: -0.02em; }
```

**Espacement des mots** : défini avec `word-spacing`.

```css
p { word-spacing: 0.1em; }
```

**Transformation du texte** : défini avec `text-transform`.

```css
uppercase { text-transform: uppercase; }
lowercase { text-transform: lowercase; }
capitalize { text-transform: capitalize; }
```

**Décoration du texte** : défini avec `text-decoration`.

```css
a { text-decoration: none; }
.underline { text-decoration: underline; }
```

## Erreurs fréquentes

**Utiliser !important de manière abusive**

```css
.button { color: blue !important; }
```

Le recours à `!important` masque les problèmes de spécificité et rend le CSS difficile à maintenir. Il est presque toujours possible de résoudre un conflit de styles en ajustant les sélecteurs.

<Callout type="warn">
```css
.button-primary { color: blue; }
.button-secondary { color: blue; }
```
Utilisez des sélecteurs plus spécifiques ou des classes distinctes au lieu de `!important`. Réservez `!important` aux cas extrêmes (ex: override de styles d'une bibliothèque tierce).
</Callout>

**Sélecteurs trop spécifiques**

```css
body header nav ul li a.button { color: blue; }
```

Ce sélecteur a une spécificité élevée (0, 2, 4) et est difficile à surcharger. De plus, il dépend strictement de la structure HTML, ce qui rend le CSS fragile.

<Callout type="warn">
```css
.button { color: blue; }
```
Utilisez des sélecteurs simples et des classes descriptives. La structure HTML peut changer sans casser le CSS.
</Callout>

**Oublier box-sizing: border-box**

```css
.container { width: 300px; padding: 20px; }
```

La largeur totale de l'élément est 340px (300 + 20*2), ce qui peut casser la mise en page si le parent a exactement 300px de large.

<Callout type="warn">
```css
* { box-sizing: border-box; }
.container { width: 300px; padding: 20px; }
```
Appliquez `box-sizing: border-box` globalement. La largeur totale de l'élément sera exactement 300px, padding inclus.
</Callout>

**Utiliser px pour toutes les tailles de police**

```css
body { font-size: 16px; }
h1 { font-size: 32px; }
```

Les tailles de police en pixels ne sont pas redimensionnables par les utilisateurs qui ont besoin de polices plus grandes pour l'accessibilité.

<Callout type="warn">
```css
html { font-size: 16px; }
body { font-size: 1rem; }
h1 { font-size: 2rem; }
```
Utilisez `rem` pour les tailles de police. L'utilisateur peut modifier la taille de base (`html`) et toutes les tailles s'ajustent proportionnellement.
</Callout>

**Confondre margin et padding**

```css
.box { margin: 20px; }
/* Attendu : espace intérieur de 20px */
```

Margin crée un espace extérieur (sépare des autres éléments). Padding crée un espace intérieur (entre le contenu et la bordure).

<Callout type="warn">
```css
.box { padding: 20px; } /* Espace intérieur */
.box { margin: 20px; } /* Espace extérieur */
```
Souvenez-vous : padding = intérieur, margin = extérieur. Le padding reçoit la couleur de fond de l'élément, le margin est toujours transparent.
</Callout>

## Exercices

<Exercise n="4.1" title='Calculer la spécificité'>
Calculez la spécificité (A, B, C) de chaque sélecteur et déterminez quelle couleur sera appliquée au paragraphe.

```css
p { color: black; }
.highlight { color: yellow; }
#content p { color: blue; }
p.highlight { color: red; }
#content .highlight { color: green; }
```

```html
<div id="content">
  <p class="highlight">Texte</p>
</div>
```
</Exercise>

<Solution>
Spécificités :
- `p` : (0, 0, 1)
- `.highlight` : (0, 1, 0)
- `#content p` : (1, 0, 1)
- `p.highlight` : (0, 1, 1)
- `#content .highlight` : (1, 1, 0)

Le paragraphe correspond aux sélecteurs : `.highlight`, `#content p`, `p.highlight`, `#content .highlight`.

Spécificités comparées :
- `#content .highlight` : (1, 1, 0) - la plus élevée
- `p.highlight` : (0, 1, 1)
- `#content p` : (1, 0, 1)
- `.highlight` : (0, 1, 0)

La couleur appliquée est `green` (du sélecteur `#content .highlight`).
</Solution>

<Exercise n="4.2" title='Comprendre le modèle de boîte'>
Créez un élément div avec les styles suivants :

```css
.box {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
  margin: 10px;
}
```

Sans `box-sizing: border-box`, quelle est la largeur totale de l'élément ? Avec `box-sizing: border-box`, quelle est la largeur totale ? Quelle est la largeur du contenu dans chaque cas ?
</Exercise>

<Solution>
Sans `box-sizing` (content-box par défaut) :
- Largeur totale = width + padding-left + padding-right + border-left + border-right + margin-left + margin-right
- Largeur totale = 200 + 20 + 20 + 5 + 5 + 10 + 10 = 270px
- Largeur du contenu = 200px

Avec `box-sizing: border-box` :
- Largeur totale = width + margin-left + margin-right
- Largeur totale = 200 + 10 + 10 = 220px
- Largeur du contenu = width - padding-left - padding-right - border-left - border-right
- Largeur du contenu = 200 - 20 - 20 - 5 - 5 = 150px
</Solution>

<Exercise n="4.3" title='Comparer les unités de mesure'>
Créez trois éléments avec les mêmes styles mais des unités différentes pour la largeur :

```css
.px { width: 300px; }
.percent { width: 50%; }
.rem { width: 20rem; }
```

Placez-les dans un conteneur de 600px de large. Quelle est la largeur de chaque élément ? Si vous changez la taille de police de base (`html`) de 16px à 20px, comment les largeurs changent-elles ?
</Exercise>

<Solution>
Avec `html { font-size: 16px; }` :
- `.px` : 300px (fixe)
- `.percent` : 50% de 600px = 300px
- `.rem` : 20 * 16px = 320px

Avec `html { font-size: 20px; }` :
- `.px` : 300px (inchangé)
- `.percent` : 50% de 600px = 300px (inchangé)
- `.rem` : 20 * 20px = 400px (changé)

Seule l'unité `rem` dépend de la taille de police de base. `px` est absolu, `%` est relatif au parent.
</Solution>

<Exercise n="4.4" title='Convertir des couleurs hexadécimales en RGB'>
Convertissez les couleurs hexadécimales suivantes en notation RGB :

1. `#ff0000`
2. `#00ff00`
3. `#0000ff`
4. `#ffffff`
5. `#000000`
6. `#808080`

Vérifiez vos conversions en créant des éléments avec ces couleurs dans un navigateur.
</Exercise>

<Solution>
1. `#ff0000` = `rgb(255, 0, 0)` (rouge)
2. `#00ff00` = `rgb(0, 255, 0)` (vert)
3. `#0000ff` = `rgb(0, 0, 255)` (bleu)
4. `#ffffff` = `rgb(255, 255, 255)` (blanc)
5. `#000000` = `rgb(0, 0, 0)` (noir)
6. `#808080` = `rgb(128, 128, 128)` (gris moyen)

Conversion : chaque paire hexadécimale représente une valeur décimale de 0 à 255. `ff` = 255, `00` = 0, `80` = 128.
</Solution>

<Exercise n="4.7" title='Résoudre un conflit de spécificité'>
Le code suivant applique une couleur rouge au paragraphe, mais vous voulez qu'il soit bleu. Modifiez le CSS (sans utiliser !important) pour que le paragraphe soit bleu.

```css
div p { color: red; }
```

```html
<div>
  <p class="blue">Texte</p>
</div>
```
</Exercise>

<Solution>
Plusieurs solutions possibles, de la moins spécifique à la plus spécifique :

```css
/* Option 1 : classe (0, 1, 0) vs (0, 0, 1) */
.blue { color: blue; }

/* Option 2 : classe sur p (0, 1, 1) vs (0, 0, 1) */
p.blue { color: blue; }

/* Option 3 : id (1, 0, 0) vs (0, 0, 1) */
#unique { color: blue; }
```

HTML modifié pour l'option 3 :
```html
<div>
  <p id="unique">Texte</p>
</div>
```

L'option 1 (classe simple) est généralement préférée pour la maintenabilité.
</Solution>

## Livrable

Transformez le CV HTML créé dans le module précédent en un document stylisé avec CSS. Le CV doit inclure :

**Structure CSS obligatoire**
- Fichier CSS externe lié au HTML
- Règle `* { box-sizing: border-box; }` au début
- Variables CSS pour les couleurs et espacements
- Organisation logique des règles (sections, typographie, layout)

**Styles obligatoires**
- Typographie cohérente (police, tailles, interlignages)
- Palette de couleurs limitée (2-3 couleurs + noir/gris)
- Mise en page avec margin et padding
- Styles pour les liens (couleur, hover)
- Styles pour le tableau (bordures, alternance)
- Effets de hover sur les éléments interactifs
- Media query pour mobile (responsive)

**Critères d'évaluation**
- [ ] CSS dans un fichier externe
- [ ] Utilisation de classes plutôt que de sélecteurs d'élément
- [ ] Variables CSS pour les valeurs réutilisées
- [ ] Spécificité des sélecteurs maîtrisée (pas de !important)
- [ ] Model de boîte compris (box-sizing: border-box)
- [ ] Unités appropriées (rem pour polices, % pour largeurs)
- [ ] Palette cohérente et contrastée
- [ ] Responsive sur mobile

**Pistes d'extension**
- Ajoutez des animations CSS (transitions sur hover)
- Créez un thème clair/sombre avec CSS variables
- Utilisez des pseudo-classes pour les effets (:hover, :focus)
- Ajoutez des ombres subtiles (box-shadow)
- Implémentez une grille CSS pour la mise en page (module suivant)

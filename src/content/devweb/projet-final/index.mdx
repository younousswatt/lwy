## Cours

### Présentation du projet

"Ma bibliothèque de films" est une application web qui permet de rechercher des films, d'afficher leurs détails, de gérer une liste de favoris, et de suivre les films visionnés. L'application utilise l'API TMDB (The Movie Database) pour récupérer les données en temps réel.

**Fonctionnalités principales** :

- Recherche de films par titre
- Affichage des résultats de recherche avec affiches
- Détails d'un film (titre, année, genre, synopsis, note)
- Ajout/Suppression des favoris (persisté dans localStorage)
- Marquage des films comme "visionnés" (persisté dans localStorage)
- Filtrage (tous, favoris, visionnés)
- Interface responsive (mobile, tablet, desktop)
- Navigation intuitive

**Stack technique** :

- HTML5 sémantique
- CSS moderne (variables, Flexbox, Grid, media queries)
- JavaScript ES6+ (modules, async/await, localStorage)
- API TMDB (fetch, gestion d'erreurs)
- Git et GitHub Pages pour le déploiement

### API TMDB

TMDB (The Movie Database) est une API gratuite qui fournit des données sur les films, séries, et acteurs.

**Obtenir une clé API** :

1. Créez un compte sur https://www.themoviedb.org/
2. Allez dans Settings → API
3. Créez une nouvelle clé API (Developer)
4. Notez la clé API (sera utilisée dans le code)

**Endpoints principaux** :

- **Recherche** : `https://api.themoviedb.org/3/search/movie?api_key=YOUR_KEY&query=titre`
- **Détails** : `https://api.themoviedb.org/3/movie/{movie_id}?api_key=YOUR_KEY`
- **Populaires** : `https://api.themoviedb.org/3/movie/popular?api_key=YOUR_KEY`

**Exemple de réponse** :

```json
{
  "results": [
    {
      "id": 550,
      "title": "Fight Club",
      "release_date": "1999-10-15",
      "poster_path": "/pB8BM7pdSp6B6Ih7QZ4DrQ3PmJK.jpg",
      "vote_average": 8.4,
      "overview": "A ticking-time-bomb insomniac..."
    }
  ]
}
```

<Callout type="warn">
Ne partagez jamais votre clé API publiquement. Dans un projet réel, elle devrait être stockée dans une variable d'environnement côté serveur. Pour ce projet, nous l'utiliserons directement dans le code, mais notez que ce n'est pas une pratique de production.
</Callout>

## Erreurs fréquentes

**Bloquer l'interface pendant les requêtes API**

```javascript
function rechercherFilms(titre) {
  const response = await fetch(url);
  const data = await response.json();
  afficherResultats(data);
}
```

L'utilisateur ne sait pas qu'une requête est en cours. L'interface semble figée.

<Callout type="warn">
```javascript
async function rechercherFilms(titre) {
  afficherLoader();
  try {
    const response = await fetch(url);
    const data = await response.json();
    afficherResultats(data);
  } catch (erreur) {
    afficherErreur(erreur);
  } finally {
    masquerLoader();
  }
}
```
Affichez toujours un indicateur de chargement pendant les requêtes asynchrones pour informer l'utilisateur.
</Callout>

**Ignorer les erreurs de l'API**

```javascript
async function rechercherFilms(titre) {
  const response = await fetch(url);
  const data = await response.json();
  afficherResultats(data);
}
```

Si l'API renvoie une erreur ou si la requête échoue, l'application plante sans message d'erreur.

<Callout type="warn">
```javascript
async function rechercherFilms(titre) {
  try {
    const response = await fetch(url);
    if (!response.ok) {
      throw new Error(`Erreur API : ${response.status}`);
    }
    const data = await response.json();
    afficherResultats(data);
  } catch (erreur) {
    afficherErreur("Impossible de charger les films. Veuillez réessayer.");
  }
}
```
Gérez toujours les erreurs asynchrones avec try/catch et affichez un message d'erreur clair à l'utilisateur.
</Callout>

**Ne pas gérer le localStorage plein**

```javascript
function sauvegarderFavori(film) {
  const favoris = JSON.parse(localStorage.getItem("favoris")) || [];
  favoris.push(film);
  localStorage.setItem("favoris", JSON.stringify(favoris));
}
```

Si localStorage est plein, l'application plante sans gestion d'erreur.

<Callout type="warn">
```javascript
function sauvegarderFavori(film) {
  try {
    const favoris = JSON.parse(localStorage.getItem("favoris")) || [];
    favoris.push(film);
    localStorage.setItem("favoris", JSON.stringify(favoris));
  } catch (erreur) {
    if (erreur.name === "QuotaExceededError") {
      afficherErreur("Espace de stockage plein. Supprimez des favoris.");
    } else {
      afficherErreur("Erreur lors de la sauvegarde.");
    }
  }
}
```
Gérez l'erreur QuotaExceededError pour informer l'utilisateur que le stockage est plein.
</Callout>

**Ignorer l'accessibilité dans l'interface**

```html
<img src="poster.jpg">
<button>+</button>
```

Les images n'ont pas d'alt, les boutons n'ont pas de labels, l'interface n'est pas accessible au clavier.

<Callout type="warn">
```html
<img src="poster.jpg" alt="Affiche du film Fight Club">
<button aria-label="Ajouter aux favoris">+</button>
```
Appliquez les principes d'accessibilité : alt sur les images, aria-label sur les boutons icônes, navigation clavier, contraste suffisant.
</Callout>

```javascript
// api.js
const API_BASE = "https://api.themoviedb.org/3";
let API_KEY = "";

export function configurerAPI(apiKey) {
  API_KEY = apiKey;
}

export async function rechercherFilms(titre) {
  const url = `${API_BASE}/search/movie?api_key=${API_KEY}&query=${encodeURIComponent(titre)}`;
  return await requeterAPI(url);
}

export async function obtenirDetails(id) {
  const url = `${API_BASE}/movie/${id}?api_key=${API_KEY}`;
  return await requeterAPI(url);
}

export async function obtenirPopulaires() {
  const url = `${API_BASE}/movie/popular?api_key=${API_KEY}`;
  return await requeterAPI(url);
}

async function requeterAPI(url) {
  try {
    const response = await fetch(url);
    if (!response.ok) {
      throw new Error(`Erreur HTTP : ${response.status}`);
    }
    const data = await response.json();
    return data;
  } catch (erreur) {
    console.error("Erreur API :", erreur);
    throw new Error("Impossible de contacter l'API");
  }
}
```

<Exercise n="13.3" title="Créer le module Storage">
Créez le module `storage.js` avec les fonctions suivantes :

1. `ajouterFavori(film)` : ajoute un film aux favoris
2. `supprimerFavori(id)` : supprime un film des favoris
3. `estFavori(id)` : vérifie si un film est dans les favoris
4. `obtenirFavoris()` : renvoie tous les favoris
5. Fonctions équivalentes pour les films visionnés

Gérez l'erreur QuotaExceededError.
</Exercise>

<Solution>
```javascript
// storage.js
const CLE_FAVORIS = "favoris";
const CLE_VISIONNES = "visionnes";

export function ajouterFavori(film) {
  const favoris = obtenirFavoris();
  if (!favoris.some((f) => f.id === film.id)) {
    favoris.push({ ...film, addedAt: new Date().toISOString() });
    sauvegarder(CLE_FAVORIS, favoris);
  }
}

export function supprimerFavori(id) {
  const favoris = obtenirFavoris().filter((f) => f.id !== id);
  sauvegarder(CLE_FAVORIS, favoris);
}

export function estFavori(id) {
  return obtenirFavoris().some((f) => f.id === id);
}

export function obtenirFavoris() {
  return charger(CLE_FAVORIS);
}

export function marquerVisionne(id) {
  const visionnes = obtenirVisionnes();
  if (!visionnes.some((v) => v.id === id)) {
    visionnes.push({ id, watchedAt: new Date().toISOString() });
    sauvegarder(CLE_VISIONNES, visionnes);
  }
}

export function obtenirVisionnes() {
  return charger(CLE_VISIONNES);
}

function charger(cle) {
  try {
    const valeur = localStorage.getItem(cle);
    return valeur ? JSON.parse(valeur) : [];
  } catch (erreur) {
    console.error("Erreur de chargement :", erreur);
    return [];
  }
}

function sauvegarder(cle, donnees) {
  try {
    localStorage.setItem(cle, JSON.stringify(donnees));
  } catch (erreur) {
    if (erreur.name === "QuotaExceededError") {
      throw new Error("Espace de stockage plein");
    }
    throw new Error("Erreur de sauvegarde");
  }
}
```
</Solution>

```javascript
// ui.js
const IMAGE_BASE = "https://image.tmdb.org/t/p/w500";

export function afficherFilms(films, conteneur) {
  conteneur.innerHTML = films.map((film) => `
    <div class="film-card" data-id="${film.id}">
      <img src="${IMAGE_BASE}${film.posterPath}" alt="${film.title}" loading="lazy">
      <h3>${film.title}</h3>
      <p>${film.releaseDate?.split("-")[0] || "N/A"}</p>
      <p>⭐ ${film.voteAverage?.toFixed(1) || "N/A"}</p>
    </div>
  `).join("");
}

export function afficherDetails(film) {
  const details = document.getElementById("details");
  details.innerHTML = `
    <div class="details-container">
      <img src="${IMAGE_BASE}${film.posterPath}" alt="${film.title}">
      <div class="details-info">
        <h2>${film.title}</h2>
        <p>${film.releaseDate?.split("-")[0] || "N/A"}</p>
        <p>⭐ ${film.voteAverage?.toFixed(1) || "N/A"}/10</p>
        <p>${film.overview || "Pas de synopsis"}</p>
        <div class="details-actions">
          <button id="btn-favori">❤️ Favori</button>
          <button id="btn-visionne">✓ Visionné</button>
          <button id="btn-retour">← Retour</button>
        </div>
      </div>
    </div>
  `;
}

export function afficherLoader() {
  const loader = document.getElementById("loader");
  loader.style.display = "block";
}

export function masquerLoader() {
  const loader = document.getElementById("loader");
  loader.style.display = "none";
}

export function afficherErreur(message) {
  const erreur = document.getElementById("erreur");
  erreur.textContent = message;
  erreur.style.display = "block";
```

```javascript
// main.js
import { configurerAPI, rechercherFilms, obtenirPopulaires, obtenirDetails } from "./api.js";
import { ajouterFavori, supprimerFavori, estFavori, marquerVisionne, obtenirVisionnes } from "./storage.js";
import { afficherFilms, afficherDetails, afficherLoader, masquerLoader, afficherErreur } from "./ui.js";

const API_KEY = "VOTRE_CLE_API";

configurerAPI(API_KEY);

// Éléments du DOM
const inputRecherche = document.getElementById("recherche");
const boutonRecherche = document.getElementById("btn-recherche");
const conteneurResultats = document.getElementById("resultats");
const conteneurDetails = document.getElementById("details");
const conteneurPopulaires = document.getElementById("populaires");

// Initialisation
async function initialiser() {
  try {
    afficherLoader();
    const data = await obtenirPopulaires();
    afficherFilms(data.results, conteneurPopulaires);
  } catch (erreur) {
    afficherErreur("Impossible de charger les films populaires");
  } finally {
    masquerLoader();
  }
}

// Recherche
async function rechercher() {
  const titre = inputRecherche.value.trim();
  if (!titre) return;

  try {
    afficherLoader();
    const data = await rechercherFilms(titre);
    afficherFilms(data.results, conteneurResultats);
  } catch (erreur) {
    afficherErreur("Impossible de rechercher les films");
  } finally {
    masquerLoader();
  }
}

// Afficher détails
async function afficherDetailsFilm(id) {
  try {
    afficherLoader();
    const film = await obtenirDetails(id);
    afficherDetails(film);
    mettreAJourBoutons(film.id);
  } catch (erreur) {
    afficherErreur("Impossible de charger les détails");
  } finally {
    masquerLoader();
  }
}

// Mettre à jour les boutons
function mettreAJourBoutons(id) {
  const btnFavori = document.getElementById("btn-favori");
  const btnVisionne = document.getElementById("btn-visionne");

  if (estFavori(id)) {
    btnFavori.textContent = "❤️ Retirer des favoris";
  } else {
    btnFavori.textContent = "❤️ Ajouter aux favoris";
  }
}

// Écouteurs d'événements
boutonRecherche.addEventListener("click", rechercher);
inputRecherche.addEventListener("keypress", (e) => {
  if (e.key === "Enter") rechercher();
});

conteneurResultats.addEventListener("click", (e) => {
  const card = e.target.closest(".film-card");
  if (card) {
    afficherDetailsFilm(parseInt(card.dataset.id));
  }
});

conteneurPopulaires.addEventListener("click", (e) => {
  const card = e.target.closest(".film-card");
  if (card) {
    afficherDetailsFilm(parseInt(card.dataset.id));
  }
});

conteneurDetails.addEventListener("click", (e) => {
  if (e.target.id === "btn-favori") {
    const id = parseInt(document.querySelector(".details-container").dataset.id);
    if (estFavori(id)) {
      supprimerFavori(id);
    } else {
      const film = { id, title: document.querySelector("h2").textContent };
      ajouterFavori(film);
    }
    mettreAJourBoutons(id);
  }

  if (e.target.id === "btn-visionne") {
    const id = parseInt(document.querySelector(".details-container").dataset.id);
    marquerVisionne(id);
    e.target.textContent = "✓ Visionné";
  }

  if (e.target.id === "btn-retour") {
    conteneurDetails.innerHTML = "";
  }
});

// Démarrage
initialiser();
```
